================================================================================
  SARAN ARSITEKTUR & TEKNOLOGI
================================================================================

📋 REKOMENDASI STACK:
   - Frontend: Bootstrap 5 + jQuery (sudah ada)
   - Payment: Midtrans (populer di Indonesia)
   - Shipping: RajaOngkir API
   - Email: PHPMailer/SMTP
   - PDF: DomPDF or TCPDF
   - Export: PhpSpreadsheet (sudah ada)
   - Search: Elasticsearch (untuk data besar)

📋 STRUKTUR TABEL BARU YANG DIBUTUHKAN:
   - cart (keranjang belanja)
   - coupons (kupon diskon)
   - shipping_address (alamat pengiriman)
   - order_status_history (riwayat status)
   - notifications (notifikasi)
   - settings (pengaturan umum)

📋 WORKFLOW ORDER YANG DISARANKAN:
   1. Customer pilih produk → tambah keranjang
   2. Checkout → isi data + alamat
   3. Pilih kurir → kalkulasi ongkir
   4. Pilih metode pembayaran
   5. Bayar → konfirmasi
   6. Admin proses → update status
   7. Kirim resi → customer tracking
   8. Selesai → review/testimonial
